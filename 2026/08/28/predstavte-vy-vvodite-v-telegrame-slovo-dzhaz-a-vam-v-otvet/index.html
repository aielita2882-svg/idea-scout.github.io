Radio Station Playlist Generator: Автоматизация создания .m3u плейлистов через Telegram

Разбор компактного open-source инструмента для тех, кому нужно быстро собирать подборки интернет-радио без ручного поиска ссылок. Бот принимает текстовый запрос и возвращает готовый файл плейлиста, который можно закинуть в любой медиаплеер.

Технический стек

Проект реализован на минималистичном, но эффективном стеке:

  • Язык: Python 3.7+
  • Telegram API: pyTelegramBotAPI (Telebot)
  • HTTP-запросы: requests
  • Источник данных: Open API Radio Browser

Как это работает под капотом

Бот работает как прослойка между пользователем и базой данных Radio Browser. Процесс обработки запроса выглядит так:

  1. Поиск: Бот принимает строку (например, “lo-fi Tokyo” или “рок Германия”) и отправляет запрос к API. Поиск идет параллельно по трем полям: названию станции, жанрам/тегам и стране.
  2. Очистка данных: Реализована фильтрация дублей по уникальному ID станции. Это исключает ситуацию, когда одна и та же станция попадает в список несколько раз из-за разных тегов.
  3. Генерация файла: На сервере динамически создается файл в формате .m3u с именем playlist_[запрос].m3u.
  4. Доставка и cleanup: Файл отправляется пользователю через Telegram API, после чего немедленно удаляется с сервера для экономии места и соблюдения гигиены файловой системы.

Безопасность и деплой

Разработчик не зашил токены в код (hardcode), что является базовым стандартом. Все чувствительные данные вынесены в config.ini.

Быстрый старт:

pip install pyTelegramBotAPI requests
# Настройка config.ini -> запуск main.py

Субъективная оценка

Почему это круто

Это отличный пример “инструментального” бота. Здесь нет перегруженного UI или бесполезных функций — только одна задача, решенная максимально эффективно. Для джунов или тех, кто хочет попрактиковаться в работе с внешними API, код читается за 30 минут и служит хорошим шаблоном для реализации аналогичных генераторов файлов.

Где применить

  • Личное использование: Быстрый поиск нишевых станций для фонового прослушивания.
  • База для проекта: Можно докрутить бота, добавив фильтрацию по битрейту (например, только 320kbps) или интеграцию с распознаванием музыки.
  • Портфолио: Чистый пример работы с API, файловой системой и конфигурационными файлами.

Подводные камни

Главный нюанс при развертывании на серверах в РФ — блокировки Telegram API. Бот не заведется “из коробки” без настроенного VPN или прокси-сервера. Это критический момент при выборе хостинга для деплоя.

Итог

Radio Station Playlist Generator — это лаконичный инструмент, который превращает хаотичный поиск по радиостанциям в одну команду в мессенджере. Минимум кода, максимум практической пользы. 100% open-source.
