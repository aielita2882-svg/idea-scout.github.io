AI Sale Agent: Автономный менеджер на стеке FastAPI, React и RAG

Типичные чат-боты в e-commerce — это обычно набор жестких скриптов и ссылок на FAQ, которые только раздражают пользователя. AI Sale Agent меняет подход, превращая чат в полноценного консультанта, который знает весь ассортимент магазина и общается на естественном языке.

Это open-source решение, которое объединяет LLM с актуальными данными вашего сайта через RAG (Retrieval-Augmented Generation).

Технический стек

Проект собран на современном и производительном стеке:

  • Backend: FastAPI (Python) — обеспечивает высокую скорость обработки запросов.
  • Frontend: React — легкий встраиваемый виджет для интеграции на любой сайт.
  • LLM: GPT-4o от OpenAI — отвечает за генерацию осмысленных и контекстных ответов.
  • Vector DB: ChromaDB — хранит эмбеддинги данных о товарах для быстрого поиска.
  • Parsing: BeautifulSoup — автоматический сбор данных с веб-страниц.
  • Voice: Whisper (STT) и TTS (Text-to-Speech) для реализации голосового интерфейса.
  • Infrastructure: Docker Compose для быстрого развертывания.

Как это работает под капотом

Схема работы системы линейна и эффективна:

  1. Индексация: Парсер на BeautifulSoup обходит указанный сайт, извлекает информацию о товарах, услугах и ценах.
  2. Векторизация: Данные разбиваются на чанки, переводятся в векторные представления и сохраняются в ChromaDB.
  3. Запрос: Когда пользователь пишет сообщение, система делает семантический поиск по базе, находит наиболее релевантные фрагменты текста.
  4. Генерация: Найденный контекст вместе с вопросом пользователя отправляется в GPT-4o. Модель генерирует ответ, опираясь строго на предоставленные данные, что минимизирует галлюцинации.

Киллер-фичи

В проекте реализованы вещи, которые отличают его от простых оберток над API:

  • Streaming (SSE): Ответы приходят потоком, как в интерфейсе ChatGPT. Пользователь видит процесс генерации в реальном времени, что улучшает UX.
  • Real-time коммуникация: Использование WebSockets для мгновенного обмена сообщениями.
  • Голосовой интерфейс: Связка Whisper + TTS позволяет клиенту общаться с ботом голосом, что критично для мобильного трафика.
  • Быстрый деплой: Весь стек упакован в Docker. Достаточно прописать OpenAI API ключ и запустить контейнеры.

Вердикт и практическое применение

Почему это круто: Это готовый шаблон для создания AI-ассистента, который реально продает. Вместо того чтобы вручную прописывать сотни интентов, вы просто «скармливаете» боту свой сайт. Возможность кастомизировать системный промпт позволяет настроить Tone of Voice под конкретный бренд (от строгого корпоративного до дружелюбного гик-стиля).

Где использовать:

  • Небольшие и средние интернет-магазины.
  • Лендинги с большим количеством технических характеристик товаров.
  • Сервисные компании с разветвленным прайс-листом.

Подводные камни:

  1. Качество парсинга: Если структура сайта сложная или контент подгружается через JS (SPA), стандартного BeautifulSoup может не хватить — потребуется заменить его на Playwright или Selenium.
  2. Стоимость токенов: При высоком трафике использование GPT-4o может стать накладным. Рекомендуется рассмотреть переход на GPT-4o-mini или локальные модели через Ollama для простых задач.
  3. Актуальность данных: База ChromaDB не обновляется автоматически в реальном времени. При изменении цен или остатков товаров потребуется перезапуск парсера и переиндексация.
