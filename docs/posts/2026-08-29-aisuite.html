🔥 aisuite ❓ Что это: Это Python-библиотека, которая создаёт единый интерфейс для работы с кучей разных Generative AI провайдеров. По сути — адаптер-обёртка, который позволяет переключаться между OpenAI, Anthropic, Google, Mistral и другими моделями буквально меняя одну строку в коде. Родился из личной боли автора, которому надоело переписывать код каждый раз, когда хочется попробовать новую модель или провайдера. ⚡ Фишки: - Единый API для всех провайдеров — пишешь код один раз, меняешь провайдера через параметр - Поддержка Chat Completions и Responses API (актуально для OpenAI) - Автоматическое переключение между моделями через простой формат: провайдер/модель - Минимальные зависимости и простая интеграция в существующие проекты 🎰 Статистика: 16 178 звёзд, Python, активный проект с регулярными обновлениями. Сообщество растёт, потому что проблема vendor lock-in в AI сейчас стоит острее некуда. 🎯 Кому пригодится: Разработчикам, которые устали переписывать интеграции каждые полгода, когда очередной провайдер выпускает killer-модель. Идеально для прототипирования, A/B тестов разных LLM и проектов, где нужно быстро сравнить ответы от разных моделей. Если ты строишь AI-продукт и не хочешь проснуться однажды с мыслью "а если OpenAI закроет нам доступ" — это мастхэв. Ну и для тех, кто любит гонять модели как перчатки — от GPT-4o до Claude до Llama без боли. 100% опенсорс
