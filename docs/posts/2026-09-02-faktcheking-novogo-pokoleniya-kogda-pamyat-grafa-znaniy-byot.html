💡 Фактчекинг нового поколения: когда память графа знаний бьёт гигантские LLM

❓ Что сделали: Ребята запилили гибридный фреймворк для проверки фактов, который сначала лезет в собственный граф знаний (Knowledge Graph), а только потом — в интернет. Внутри сидят Sentence-BERT для семантического поиска плюс Natural Language Inference для оценки противоречий. Если внутренней памяти не хватает — подключается «адверсариальный трибунал» из трёх агентов: один защищает утверждение, другой атакует, третий выносит вердикт. Ну и вишенка — система сама дообучает свой граф знаний, добавляя подтверждённые факты обратно в память.

🎰 Результаты: На бенчмарке по COVID-мисинформинции фреймворк выбил 97.4% точности и 92.6% macro-F1. Для сравнения: Llama 3.3 70B — это огромная модель на 70 миллиардов параметров — набрала только 87.7% и 86.3% соответственно. То есть специализированная система с графом знаний и тремя агентами обскакала монстра, у которого параметров больше, чем у некоторых государств — населения. При этом механизм уверенности на основе графа заметно сократил количество ненужных запросов в веб.

✈️ Зачем это нужно: Идеальный инструмент для журналистов, fact-check платформ и модераторов соцсетей, которые тонут в потоке дезинформации. В эпоху, когда каждый второй пост про вакцины или выборы — потенциальная ложь, такая «память + трибунал» архитектура даёт не просто вердикт, а объяснимое решение с конкретными триплетами фактов. И да, это удар по всем, кто думал, что без гигантской LLM качественного фактчекинга не бывает — оказывается, правильная архитектура с компактными моделями бьёт тяжёлые трансформеры.
