Хватит сжигать бюджеты и ждать неделями, пока ваши агенты проползут через бесконечные тесты.

16 September 2026

Теги: АгентыИИ-агентДанныеОбучение

Что это 💡 DualViewEval - это продвинутый метод двухвидового реляционного обучения, созданный для того, чтобы сделать бенчмаркинг ИИ-агентов быстрым и дешевым. Вместо того чтобы прогонять модель через тысячи однотипных задач, система создает компактные, но репрезентативные мини-датасеты, которые предсказывают финальный результат с пугающей точностью.

В чем фишка 🚀 Авторы решили не просто смотреть на итоговый балл (который часто бывает обманчив), а залезть «под капот» процесса. - Анализ траекторий: система изучает путь агента к решению, а не только факт успеха. - Шесть сигналов процесса: выделены специфические метрики выполнения, которые напрямую коррелируют с итоговым качеством. - Двойной взгляд: метод совмещает данные об исходах и деталях процесса (Dual-View). - Экстремальное сжатие: на тестах APEX-Agents и BFCL удалось добиться сокращения объема данных в 24-40 раз. - Высокая точность: средняя абсолютная ошибка (MAE) упала на 14.5-28.2% по сравнению с аналогами. - Диагностика: мини-датасеты не просто дают цифру, а подсвечивают конкретные слабые места агента.

Кто создатель 🎯 Проект разработан группой исследователей в области машинного обучения, которые устали от неэффективности традиционных методов оценки LLM-агентов.

Статистика ⚡ Метод был обкатан на пяти крупнейших бенчмарках. На SWE-bench Verified он показал рост корреляции Kendall’s τ на 7.2% относительно EssenceBench. Основной стек - Python и фреймворки для глубокого обучения. Активность вокруг проекта растет, так как индустрия остро нуждается в дешевой валидации.

Для кого 💡 В первую очередь для ML-инженеров и разработчиков автономных агентов. Если ваш пайплайн тестирования занимает вечность, а счета за API заставляют нервно икать - этот инструмент для вас. Также будет полезно исследователям, которые создают новые метрики оценки ИИ.

Мое мнение 🚀 Идея с «двумя взглядами» - это просто база. Раньше мы пытались сжать тесты, глядя только на ответ «правильно/неправильно», что напоминало попытку оценить качество написания кода по количеству ошибок компиляции. DualViewEval же смотрит на логику.

Главный подвох может быть в сложности первичной настройки сигналов процесса для специфических, узконишевых задач. Но даже с этим, возможность сократить тесты в 40 раз - это слишком жирный плюс, чтобы его игнорировать. Стоит пробовать, если вы не хотите тратить жизнь на ожидание логов.

Заключение DualViewEval превращает громоздкий и дорогой процесс оценки агентов в элегантный и быстрый инструмент. Это не просто оптимизация, а переход к более умному, диагностическому подходу в разработке ИИ.
