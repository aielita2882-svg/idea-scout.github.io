Джек Дорси, экс-глава Twitter, решил выкатить в открытый доступ исходный код фреймворка для управления бизнес-процессами, где ИИ-агенты косят под полноценных членов команды. 🚀 Алгоритм действий следующий: сначала клонируете репозиторий и поднимаете свой сервер, который будет рулить каналами, поиском, Git и всякими автоматизациями. 📊 Дальше — меньше: просто добавляете агента в подходящий канал в качестве очередного участника, раздаете ему права и начинаете взаимодействовать в режиме реального времени. ⌨️ ⚡ Источник
