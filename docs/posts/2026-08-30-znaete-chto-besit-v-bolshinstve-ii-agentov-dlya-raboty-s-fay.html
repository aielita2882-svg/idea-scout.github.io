Знаете, что бесит в большинстве «ИИ-агентов для работы с файлами»? Что они не работают с файлами. Они болтают. А ты сидишь и копируешь их текст руками в редактор, как обезьянка. 🔥 Сороковой день моего марафона — и я наконец-то написала нормального агента, который реально лезет в проект и что-то там меняет. Ставишь цель на естественном языке — он сам планирует, читает файлы, ищет по нескольким сразу, анализирует git-историю, создаёт новые файлы, правит существующие. И показывает результат как нормальный git diff, а не как стену текста. Внутри два режима тулов, и это прям красиво: ⚡ Direct (по умолчанию) — реальный bash плюс прямые операции с файлами, как в Claude Code. Перед каждым изменением спрашивает y/N. Хочешь автономно — флаг --yes, и агент идёт делать. 🎯 MCP-режим (--mcp) — безопасный конфайнмент: все пути заперты в проекте, .env и .git заблокированы, bash недоступен. С --dry-run вообще получаешь превью diff без записи на диск. Один и тот же ChatAgent под капотом — отличается только бэкенд инструментов. Никакой магии, чистая инженерия. Что я гоняла на демо-сценариях? Генерация CHANGELOG.md по истории коммитов, поиск всех упоминаний API по проекту, создание ADR с контекстом из кода, проверка инвариантов вроде «никаких секретов в клиентском коде». Каждый шаг — function calling над файловыми тулами (fs_read, fs_grep, fs_create, fs_edit), плюс run_checks для синтаксиса Python после правок. Агент реально инициирует работу с файлами сам, а не ждёт, пока ты скажешь «открой файл X». Под капотом DeepSeek, порт моих дней 31–32 на MCP, плюс приличная обработка diff-ов через свой diffutil. Воспроизводимость проверила — повторный запуск той же цели даёт эквивалентный результат, откат через git checkout тоже работает штатно. Если устали от агентов-болтунов, которые «думают, что делают» — заходите посмотреть на код. Там честный goal-oriented подход без иллюзий. 👉 Больше таких находок без воды — в нашем Telegram-канале.
