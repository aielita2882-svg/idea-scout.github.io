# Grok Bot 0.18.0: исходники утекли через source maps

После истории с утечкой Claude Code казалось, что предел абсурда достигнут. Ан нет. На днях выяснилось, что релиз Grok Bot 0.18.0 от Cursor вышел в свет вместе с картами исходного кода — source maps. Один разработчик заметил это, собрал клиентский код заново и выложил на GitHub.

## Что произошло

JavaScript в продакшене обычно сжимают и обфусцируют до нечитаемой массы. Source maps существуют для отладки — они связывают эту массу с исходными файлами и структурой проекта. Cursor просто закинула эти карты в релизную сборку. Мелкий косяк? Не совсем.

Трейс привел к исходникам Grok Bot. Клиентский код восстановили практически полностью.

## Что внутри

Теперь любой желающий может изучить:

- **координатор агентов** — как боты общаются между собой
- **маршрутизация моделей** — какие модели выбираются и когда
- **локальное выполнение** — механизм запуска кода
- **протоколы** — внутреннее API и форматы сообщений

Это не полный исходник Cursor. Но для компании, которая строит AI-инструменты для программирования, ситуация иронична до неприличия.

## Практика: уже форкнули

Восстановленную версию уже начали модифицировать. В форках появилось:

- поддержка Claude Code, Codex и OpenRouter
- запуск всего локально в Docker без привязки к удалённой инфраструктуре Cursor

То есть из баг-репорта получился вполне рабочий форк с открытым клиентом.

## Зачем это нужно

Не для того, чтобы копировать. Анализ исходников реальных AI-продуктов — это:

- **понимание паттернов** — как другие решают задачи координации агентов
- **интеграции** — свой клиент вместо проприетарного
- **безопасность** — прозрачность того, что отправляется на сервер

Мне кажется, это ценнее любого маркетингового описания продукта. Смотришь в код — и видишь реальные приоритеты.

## Резюме

Репозиторий, скорее всего, проживет недолго — DMCA никто не отменял. Но форки уже разлетелись. Если интересно поковыряться в чужом коде — качайте, пока лежит.
