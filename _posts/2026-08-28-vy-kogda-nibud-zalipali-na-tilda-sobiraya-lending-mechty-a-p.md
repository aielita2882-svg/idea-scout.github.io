# Автоматизируем email-рассылки с Tilda: webhook + Yandex Cloud + Unisender

Заполнил посетитель форму на лендинге — и тут же получает персонализированное письмо. Звучит как задача для enterprise-системы за сотни тысяч? А вот и нет. Разбираем связку, которая работает на базе Yandex Cloud Functions и Unisender API.

## Проблема

Красивый сайт на Tilda собран, лиды идут, но дальше — ступор. Менеджер открывает почту, копирует данные из заявки, пишет ответ вручную. Если за день десять заявок — окей. Если пятьдесят — начинается хаос и потерянные контакты.

Классический сценарий «красивый сайт — мёртвая база». Лечится элементарно: автоматизация отправки писем через вебхук.

## Решение: Tilda + Yandex Cloud Functions + Unisender

Схема работы:

1. Посетитель заполняет форму на Tilda
2. Tilda отправляет POST-запрос на webhook
3. Yandex Cloud Function ловит данные (имя, email)
4. Скрипт `webhook_sender.py` формирует персонализированное письмо
5. Unisender отправляет сообщение адресату

Никаких ручных действий. Заполнил форму — через секунды клиент получает «Привет, Анна, вот ваш материал».

## Как это устроено технически

**Yandex Cloud Functions** выступает в роли обработчика. Вы создаёте функцию, настраиваете триггер на HTTP-запрос, вставляете код `webhook_sender.py`. Функция принимает JSON с данными формы, извлекает `name` и `email`, формирует тело письма и дёргает API Unisender.

**Unisender** — сервис рассылок с API для программной отправки. Относительно недорогой, без привязки к ежемесячным подпискам на «конструкторы писем за 999₽/мес».

Код функции минимален по объёму: парсинг тела запроса, валидация данных, вызов метода `sendEmail` через REST API Unisender. Никаких фреймворков, никаких зависимостей кроме стандартной библиотеки Python и requests.

## Что понадобится настроить

- Аккаунт в Yandex Cloud с включённым Cloud Functions
- API-ключ Unisender
- Настройка webhook в Tilda (раздел «Формы» → «Интеграции»)
- Публикация функции с указанием `sender_email`

Всё логично, но есть нюанс.

## Моё мнение

Идея отличная. Для тех, кто устал платить за громоздкие CRM с десятками неиспользуемых функций — это реальный глоток свежего воздуха. Результат: автоматическая отправка персонализированных писем без дорогих сервисов. Масштабируемо, бюджетно, один раз настроил — работает.

Но.

Если вы не разработчик, готовьтесь к танцам с бубном. Инструкция требует разобраться с Yandex Cloud Functions, получить API-ключи, что-то публиковать, вставить `sender_email`. Пара вечеров на изучение документации — и всё заработает. Но «из коробки» не получится.

**Вердикт:** связка Tilda + Yandex Cloud Functions + Unisender — рабочий инструмент для тех, кто хочет один раз настроить и забыть. Не rocket science, но и не для слабонервных. Если у вас небольшой проект и хочется автоматизировать email-рассылки без боли — вполне себе вариант.
