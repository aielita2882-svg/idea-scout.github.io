# TradingAgents: Мультиагентный LLM-фреймворк для финансового трейдинга

TradingAgents — это попытка перенести структуру классического хедж-фонда в среду LLM. Вместо того чтобы полагаться на один промпт к GPT-4 или Claude, фреймворк разворачивает целую экосистему специализированных агентов, которые взаимодействуют друг с другом для принятия торговых решений.

## Архитектура системы

Основная проблема одиночных LLM в трейдинге — галлюцинации и склонность к подтверждению одной точки зрения (confirmation bias). TradingAgents решает это через ролевую модель и иерархию:

1. **Аналитический слой**: 
   - **Фундаментальные аналитики**: работают с отчетами, макроэкономикой и показателями компаний.
   - **Сентимент-аналитики**: парсят соцсети и новости, вычленяя рыночные настроения.
   - **Технические аналитики**: обрабатывают графики и индикаторы.
   - **Новостные аналитики**: отслеживают события в реальном времени.

2. **Слой принятия решений (Дебаты)**:
   Здесь реализован механизм «Быки против Медведей». Два противоположных лагеря агентов пытаются разбить тезисы друг друга. Это заставляет систему искать слабые места в стратегии до того, как будет открыта позиция.

3. **Контрольный слой**:
   - **Трейдер**: синтезирует итоги дебатов в конкретный торговый сигнал.
   - **Риск-менеджеры**: проверяют сделку на соответствие лимитам и риск-профилю.
   - **Управляющий фондом**: выносит финальный вердикт (Approval/Reject).

## Технический стек и метрики

- **Язык**: Python.
- **Популярность**: ~100k звезд на GitHub, высокая скорость форканья и активный вклад комьюнити.
- **Данные**: Гибкий пайплайн интеграции внешних API (фундаменталка, новости, технические данные).

## Практическое применение

Фреймворк можно использовать в следующих сценариях:
- **Построение исследовательских пайплайнов**: автоматизация сбора и первичного анализа данных по сотням активов.
- **Бэктестинг гипотез**: проверка того, как мультиагентная система отработала бы на исторических данных.
- **Разработка собственных MAS (Multi-Agent Systems)**: архитектура проекта — отличный референс по организации иерархии и обмена сообщениями между агентами с разными ролями.

## Субъективная оценка

**Почему это круто:**
Реализован полноценный механизм Adversarial Prompting через дебаты. Это на порядок надежнее, чем простой Chain-of-Thought, так как система принудительно ищет контрпримеры.

**Подводные камни:**
1. **Стоимость токенов**: Огромное количество агентов, которые переписываются друг с другом, сжигает бюджет на API очень быстро. Для продакшена потребуются либо очень дешевые модели (GPT-4o-mini), либо локальные LLM (Llama 3 / Mistral) через vLLM/Ollama.
2. **Задержки (Latency)**: Многоуровневое согласование исключает использование фреймворка в HFT (высокочастотном трейдинге). Это инструмент для свинга или долгосрочного инвестирования.
3. **Риски**: Несмотря на наличие «риск-менеджеров», LLM все еще могут ошибаться в расчетах.

**Вердикт**: Мощный инструмент для квантов и AI-инженеров. Идеален для исследований и автоматизации аналитики, но требует жесткого внешнего контроля при работе с реальным капиталом.
