В трендах GitHub поднялся OpenSandbox  — песочница для ИИ-агентов прямо от Alibaba.
Суть: поднимаешь изолированное окружение, где агенты могут выполнять код, шастать по вебу или управлять рабочим столом. И да, OpenSandbox не привязан к Python — официальные SDK есть для Python, Java/Kotlin, TypeScript, C# и даже Go. Плюс CLI и MCP-сервер для Claude Code и Cursor.
Что до изоляции — используются gVisor, Kata Containers и Firecracker microVM. Всё это можно запустить локально через Docker или развернуть в продакшене.
