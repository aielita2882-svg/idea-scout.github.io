# ChatGPTbotTelegram: человек как архитектор, нейросеть как исполнитель

Иногда встречаются проекты, которые интересны не сами по себе, а как доказательство концепции. ChatGPTbotTelegram — один из таких.

## О чём речь

Телеграм-бот, который использует OpenAI API для генерации ответов. Звучит привычно? Держите интригу: автор признаётся, что написал бота руками, но львиную долю кода сгенерировала нейросеть. Человек выступил архитектором — сформулировал задачу, описал требования, собрал результат. Остальное сделал ChatGPT.

## Стек

- **flask** — веб-фреймворк для обработки запросов
- **pyTelegramBotAPI** — обёртка для Telegram Bot API
- **OpenAI API** — доступ к языковой модели
- **nltk** — библиотека для обработки текста

Ничего экзотического. Для учебного проекта — вполне достаточный набор.

## Зачем это нужно

Автор честно обозначил цель: разобраться, на что реально способен ChatGPT в роли кодера. Не маркетинговые обещания, а практический эксперимент. Сформулировал задачу — посмотрел, что получилось — сделал выводы.

## Моё мнение

Подход рабочий, но с оговорками. Делегировать код нейросети — это как нанять бригаду, которую ты никогда не видел. Может выйти шедевр, а может прилететь баг, который будешь дебажить три дня. Вайбкодинг работает только если ты понимаешь, что тебе прислали. Иначе вместо разработчика получаешь заложника собственного кода.

**Плюсы такого подхода:**
- Быстрое прототипирование
- Освобождение времени на архитектурные решения
- Практика промптинга — навык, который становится всё нужнее

**Минусы:**
- Качество кода непредсказуемо
- Без понимания технологий не обойтись
- Документацию всё равно приходится читать самому

## Кому полезно

Если вы хотите понять, где проходит граница между «промптнул и забыл» и «написал осознанно» — этот репозиторий хорошая отправная точка. Разберётесь в связке Flask + Telegram + OpenAI и заодно протестируете, насколько хорошо нейросеть понимает ваши задачи.
