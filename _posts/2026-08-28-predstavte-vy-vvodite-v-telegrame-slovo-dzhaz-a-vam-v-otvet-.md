# Radio Station Playlist Generator: бот, который собирает плейлисты за тебя

Представьте: набираете в Телеграме слово "джаз" — и получаете готовый .m3u плейлист с десятком радиостанций со всего мира. Никакого ручного копания на сайтах, никакого копирования ссылок по одной. Именно это делает Radio Station Playlist Generator.

## Что под капотом

Стек минималистичный, но рабочий:

- **Python 3.7+**
- **pyTelegramBotAPI** — общение с Telegram
- **Radio Browser API** — источник станций
- **requests** — HTTP-запросы

Бот принимает любое текстовое сообщение и ищет совпадения сразу по трём направлениям:

- название радиостанции
- жанр или тег
- страна

Хотите "lo-fi Tokyo"? Пожалуйста. "Рок Германия"? Без проблем.

## Архитектура: мелочи решают

Фильтрация дублей реализована по уникальному идентификатору станции — в плейлисте не будет мусора. Динамическая генерация файлов `playlist_запрос.m3u` с автоматической отправкой пользователю и удалением временных файлов с сервера. Никаких утечек: токен вынесен в отдельный `config.ini`, а не зашит в код.

Это базовые вещи, но многие начинающие разработчики о них забывают.

## Важный нюанс для России

Для стабильной работы необходим VPN или настроенный прокси для обхода блокировок серверов Telegram. Это не баг — это суровая реальность. Если собираетесь разворачивать бота, позаботьтесь о туннеле заранее.

## Быстрый старт

```bash
pip install pyTelegramBotAPI requests
```

1. Получите токен бота у @BotFather
2. Запишите токен в `config.ini`
3. Запустите `python bot.py`

Готово. Пять минут от идеи до работающего бота.

## Зачем это нужно

Код читается за полчаса с чашкой кофе. Это идеальная стартовая точка для нескольких сценариев:

- **Портфолио** — реальный API, реальный результат, минимум строк кода
- **Изучение Telegram API** — понятная структура, без оверхэда
- **Основа для чего-то большего** — добавьте кэширование, клавиатуры, inline-режим

Маленький бот, а душа в нём большая. Сохраняйте, тестируйте, дорабатывайте под себя.
