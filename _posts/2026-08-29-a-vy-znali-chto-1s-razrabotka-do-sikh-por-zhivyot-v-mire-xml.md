# Agenter: AI-агент для 1С, который понимает вашу конфигурацию

## Проблема

Если вы хоть раз пытались автоматизировать что-то в 1С:Предприятие 8.3, вы знаете этот путь: XML-выгрузки, ручные правки метаданных, Конфигуратор, который запускается вечность. Типичный рабочий процесс выглядит так: экспорт в XML, grep по файлам, ручная правка, обратный импорт. Джуны месяцами ковыряют структуру, пока не поймут, как что работает.

**Agenter** закрывает эту боль. Это локальный AI-агент, который встраивается прямо в платформу 1С и понимает структуру ваших метаданных.

## Архитектура

```
┌─────────────────────────────────────────────────┐
│              Agenter (PyWebView)                │
│         Нативное окно, без браузера             │
├─────────────────────────────────────────────────┤
│              FastAPI (бэкенд)                   │
├─────────────────────────────────────────────────┤
│         Claude Agent SDK                        │
│    LLM-цикл с детерминистической               │
│    диспетчеризацией стадий                      │
├─────────────────────────────────────────────────┤
│  67 PowerShell-скиллов  │  BSL Atlas + SQLite   │
│  для модификации XML    │  для поиска по конфе  │
└─────────────────────────────────────────────────┘
```

Ключевое здесь — **детерминистическая диспетчеризация**. Каждая стадия плана знает свой ожидаемый tool. Никакого хаоса, никаких галлюцинаций LLM. Это не generic AI-подход, а специализированная система, заточенная под конкретную задачу.

## 67 скиллов и 226 тестов

Под капотом — 67 PowerShell-скиллов для модификации XML-метаданных 1С. Почему PowerShell, а не Python? Потому что если Python-процесс упадёт посреди модификации, вы получите половинчатый результат. PowerShell-скрипты атомарны — либо выполняются целиком, либо нет.

Каждый скилл покрыт регрессионными тестами. Полная прогонка — **7 секунд**. Это не маркетинг, это цифры из CI/CD.

> Test-first подход: каждый продакшн-баг сначала становится регрессионным тестом, и только потом фиксом. Иначе 67 скиллов превращаются в whack-a-mole.

## Приватность

Архитектура — мечта параноика:

- Один процесс, локальные данные, **без облака**
- В Anthropic улетают только промпты и схемы tool-вызовов
- XML расширения, индекс конфигурации, исходники — всё на вашей машине
- BSL Atlas с SQLite-индексом работает локально

Если у вас есть ограничения по передаче данных, Agenter не нарушит их.

## Требования

- Windows 10/11
- Python 3.11+
- PowerShell 5.1
- 1С:Предприятие 8.3.27+
- Ключ Anthropic API

Запуск — один `start.bat`. В нативном окне открывается веб-UI, и вы работаете с агентом через привычный интерфейс.

## Практическая ценность

Для 1С-разработчиков это может стать переломным моментом. Рынок автоматизации 1С обычно сводится к двум вариантам: «наймите джуна, пусть ковыряет XML руками» или «купите готовое расширение, которое не совсем то». Agenter даёт третий путь — полноценный AI-помощник, который понимает структуру метаданных и умеет с ними работать.

Проект пока в early development, делается одним разработчиком для собственного ERP на 1С. Но база серьёзная: 67 скиллов, 226 тестов, продуманная архитектура. Если вы пилотируете расширения для 1С и устали от рутины — присмотритесь.
