# Agenter: AI-агент для автоматизации метаданных 1С:Предприятие

Разработка под 1С традиционно считается консервативной: XML-выгрузки, ручные скрипты и тяжеловесный Конфигуратор. Agenter — это попытка перенести современный LLM-стек в этот пайплайн, создав локального AI-агента, который берет на себя рутину по модификации метаданных.

## Технический стек

Проект построен по принципу минимализма с упором на локальное хранение данных и детерминизм:

*   **Frontend:** PyWebView (нативное окно, исключающее запуск полноценного браузера).
*   **Backend:** FastAPI.
*   **LLM Orchestration:** Claude Agent SDK.
*   **Поиск по конфигурации:** BSL Atlas с индексом на SQLite.
*   **Слой исполнения:** PowerShell (67 специализированных скиллов для работы с XML-метаданными).

## Как это работает

В основе Agenter лежит LLM-цикл с детерминистической диспетчеризацией стадий. В отличие от классических чат-ботов, здесь каждая стадия плана жестко привязана к ожидаемому инструменту (tool). Это минимизирует галлюцинации и исключает хаотичный вызов функций.

### Ключевые инженерные решения:

1.  **Изоляция модификаций:** Выбор PowerShell в качестве исполнителя обусловлен отказоустойчивостью. Если Python-процесс упадет, изменения в XML не будут повреждены или прерваны на полпути.
2.  **Test-First подход:** Система включает 226 регрессионных тестов, распределенных по 67 файлам. Полный прогон занимает 7 секунд. Любой баг в продакшене сначала фиксируется тестом, и только затем исправляется.
3.  **Безопасность данных:** В облако Anthropic отправляются только промпты и схемы вызовов инструментов. Индекс конфигурации, исходники и XML-расширения остаются локально на машине разработчика.

## Практическое применение

Agenter предназначен для автоматизации создания и правки расширений 1С. Вместо того чтобы вручную править XML или часами искать нужный объект в Конфигураторе, разработчик делегирует это агенту, который понимает структуру метаданных.

**Системные требования:**
*   ОС: Windows 10/11.
*   Среда: Python 3.11+, PowerShell 5.1.
*   Платформа: 1С:Предприятие 8.3.27+.
*   API: Ключ Anthropic.

Запуск осуществляется через один `start.bat`, который поднимает бэкенд и открывает веб-интерфейс в нативном окне.

## Субъективная оценка

**Почему это круто:**
Это первый вменяемый пример применения Agentic Workflow в экосистеме 1С. Переход от «напиши мне код для модуля» к «измени структуру метаданных в расширении» — это качественный скачок. Использование BSL Atlas для индексации делает агента контекстно-зависимым, что критично для огромных ERP-систем.

**Подводные камни:**
1.  **Зависимость от Claude:** Весь интеллект завязан на API Anthropic. Переход на локальные LLM (через Ollama или vLLM) может потребовать перенастройки промптов и логики диспетчеризации.
2.  **Риски XML:** Несмотря на тесты, автоматическая правка метаданных — это всегда риск «сломать» конфигурацию. Обязательно использование систем контроля версий (Git) и бэкапов.

**Вердикт:**
Инструмент для тех, кто пишет сложные расширения и устал от ручного ковыряния в XML. Проект в стадии early development, но архитектурно выглядит очень крепко.

100% Open Source.
