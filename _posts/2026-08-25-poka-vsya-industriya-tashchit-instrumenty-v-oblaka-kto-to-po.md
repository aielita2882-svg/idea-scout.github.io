# Браузерный 3D-редактор: CAD без установки софта

Весь мир несётся в облака, а кто-то сделал ход конём — запустил полноценный 3D-редактор прямо в браузере. Без регистраций, без подписок, без гигабайтов установки.

## Что умеем

Редактор заточен под **локальную работу** — никаких утечек данных на сторону. Функционал покрывает базовые сценарии:

- **Моделирование форм** — базовые примитивы, булевы операции, вырезание отверстий
- **Импорт STL** — загружаете готовые меши из других пакетов
- **Экспорт** — на выходе готовые файлы для печати или дальнейшей обработки

Для 3D-печатников и быстрого прототипирования — более чем достаточно.

## Фича, которая выделяет

Здесь есть **встроенный MCP-сервер**. Для тех, кто не в курсе: MCP (Model Context Protocol) — это способ, которым AI-агенты взаимодействуют с внешними инструментами. Теперь нейросети могут:

- Читать текущую сцену
- Создавать и модифицировать объекты
- Управлять параметрами модели

Другими словами, можно попросить языковую модель добавить фаску к детали или сгенерировать параметрическую деталь по описанию. AI-ассистент в роли 3D-дизайнера — звучит как будущее, которое уже наступило.

## Зачем это нужно

**Во-первых**, для быстрого прототипирования. Открыл вкладку — и рисуешь. Не нужно запускать тяжёлый Fusion 360 или ждать, пока Blender загрузится.

**Во-вторых**, для обучения. Преподаёшь 3D-моделирование — студенты сразу работают, без танцев с установкой софта на разные ОС.

**В-третьих**, для интеграции с AI-пайплайнами. MCP-сервер превращает редактор в инструмент, которым может управлять агент на основе LLM. Это открывает сценарии автоматизации, которые раньше требовали отдельного API.

## Открытый код

Проект **100% опенсорс**. Можно форкнуть, запилить свой форк для специфических задач или просто почитать код, чтобы понять, как работает браузерный CAD.

## Моё мнение

Это не замена профессиональным CAD-системам. Но как **быстрый инструмент для прототипирования**, который работает везде, где есть браузер — это топ. А MCP-интеграция делает его особенно интересным для тех, кто строит AI-агентов, работающих с геометрией.
