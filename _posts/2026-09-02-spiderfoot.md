🔥 SpiderFoot

❓ Что это: SpiderFoot — это автоматизированный инструмент для OSINT (Open Source Intelligence), который сканирует сотни источников в интернете, чтобы собрать данные о цели: доменах, IP-адресах, email-адресах, именах, утечках и многом другом. По сути это швейцарский нож для разведки по открытым источникам, который помогает выстроить полную картину твоей (или чужой) поверхности атаки. Проект существует уже много лет и считается одним из must-have инструментов в арсенале любого безопасника, пентестера или threat intelligence аналитика.

⚡ Фишки:
- Более 200 встроенных модулей для сбора данных из разных источников: DNS, WHOIS, Shodan, HaveIBeenPwned, соцсети, dark web и куча всего остального
- Графовая визуализация связей между найденными сущностями — сразу видно, как домен, IP и email связаны между собой через общие инфраструктурные следы
- Запуск через веб-интерфейс или CLI, есть API для интеграции в пайплайны
- Поддержка сканирования по одному объекту или по списку целей, плюс можно настраивать глубину разведки

🎰 Статистика: более 21 600 звёзд на GitHub, написан на Python, активно поддерживается сообществом и автором, регулярно обновляется и пополняется новыми модулями. Один из самых популярных OSINT-проектов на платформе.

🎯 Кому пригодится: пентестерам и red team, которым нужно быстро собрать инфу о цели перед атакой (куда копать дальше). Специалистам по threat intelligence для мониторинга упоминаний бренда, утечек и потенциальных угроз. Ну и обычным параноикам, которые хотят проверить, сколько же их персональных данных раскидано по интернету — иногда результаты сканирования самого на себя шокируют сильнее любого хоррора.
