# SpiderFoot: OSINT-сканер, который знает о вас больше, чем вы сами

## Что за зверь

SpiderFoot — это **автоматизированный инструмент для OSINT-разведки**, который за один запуск обходит сотни открытых источников и собирает разведывательные данные о любой цели. Домены, IP-адреса, email-адреса, имена людей, данные утечек, следы в соцсетях, информация из dark web — всё это агрегируется в единый отчёт.

По сути, это конструктор для построения полной картины поверхности атаки. Запустил сканер — получил структурированную базу знаний о цели. Дальше уже решаешь, куда копать.

Проект не новый — развивается много лет и стал де-факто стандартом в арсенале любого безопасника, пентестера или аналитика threat intelligence. Если вы ещё не знакомы — считайте, что вам показали скрытый уровень.

## Фичи, ради которых стоит попробовать

**200+ модулей сбора данных.** Это не преувеличение. Сканер умеет дёргать информацию из DNS и WHOIS, подключаться к Shodan, HaveIBeenPwned, VirusTotal, десяткам сервисов пассивной разведки. Каждый модуль — отдельный источник. Можно запустить всё сразу или выбрать только нужное.

**Графовая визуализация.** Найденные сущности не просто лежат списком — SpiderFoot строит интерактивный граф, где видно, как домен связан с IP, IP — с email, email — с аккаунтом на GitHub. Это не игрушка, а реально полезная фича для понимания инфраструктурных связей и обнаружения неочевидных пересечений.

**CLI и веб-интерфейс.** Запускаете через терминал — получаете вывод в JSON или CSV. Предпочитаете GUI — поднимаете веб-сервер и работаете через браузер. Есть API для интеграции в собственные пайплайны автоматизации.

**Гибкость разведки.** Можно сканировать одну цель, а можно загрузить список — например, весь список доменов компании. Настраивается глубина: поверхностный сбор или глубокое погружение по всем модулям.

## Цифры и технологии

- **21 600+ звёзд на GitHub** — один из самых популярных OSINT-проектов на платформе
- Написан на **Python** — легко форкать, модифицировать, писать свои модули
- Активно поддерживается автором и сообществом, регулярно выходят обновления с новыми источниками

## Кому это нужно

**Пентестерам и red team.** Быстро собрать информацию о цели перед атакой — критически важный этап. SpiderFoot экономит часы ручного поиска. Получил результат — уже знаешь, куда направлять усилия.

**Threat intelligence специалистам.** Мониторинг упоминаний бренда, отслеживание утечек, связанных с компанией, выявление фишинговых доменов — всё это автоматизируется.

**Параноикам и просто любопытным.** Запустите сканирование на самого себя. Серьёзно. Результаты часто шокируют — количество данных о вас в открытых источниках превышает ожидания. Это полезно для понимания собственной поверхности атаки и осознанного управления цифровым следом.

## Почему это круто

SpiderFoot решает главную проблему OSINT-разведки — **время**. Ручной сбор данных из десятков источников занимает часы. Автоматизация сокращает это до минут. При этом качество не страдает — вы получаете структурированные данные, а не хаотичный набор ссылок.

Модульная архитектура — отдельный плюс. Можно собрать кастомный набор модулей под конкретную задачу, не таща лишнее. А если нужного источника нет — пишешь свой модуль на Python за пару часов.

Графовая визуализация заслуживает отдельного внимания. Когда видишь на одной диаграмме, что корпоративный email john@company.com фигурирует в утечке с форума, а домен mail.company.com указывает на тот же IP, что и фишинговый сайт на хостинге — это уже не просто данные, а actionable intelligence.

## Быстрый старт

```bash
# Установка
pip install spiderfoot

# Запуск веб-интерфейса
sf.py -l 127.0.0.1:5001

# CLI-сканирование цели
sf.py -s example.com -m sflist -o json
```

Документация подробная, сообщество отзывчивое. Если застряли —答案 почти всегда найдёте в GitHub Issues или на форуме.

**Итог:** SpiderFoot — это не просто тулза, а полноценная OSINT-платформа. Если вы в безопасности, разведке или просто интересуетесь тем, что о вас знает интернет — попробуйте. Потратите 15 минут на установку, сэкономите дни на ручном сборе данных.
