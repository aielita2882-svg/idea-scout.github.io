# Agent File Operations: когда ИИ реально работает с кодом, а не болтает

Большинство «ИИ-агентов для работы с файлами» — это болтуны. Генерируют текст, ты копируешь руками в редактор. Знакомо? Сороковой день марафона принёс решение: агент, который **сам лезет в проект и что-то меняет**.

## Суть проблемы

Классический подход: ИИ описывает изменения, а исполнение — на тебе. Каждый файл открывать, копировать, вставлять. Обезьянья работа. Хочется иного: поставил цель на естественном языке — получил результат.

## Что умеет агент

Агент самостоятельно:

- Планирует последовательность действий
- Читает файлы проекта
- Ищет по нескольким файлам одновременно
- Анализирует git-историю
- Создаёт новые файлы
- Правит существующие
- Показывает результат как **git diff**, а не стену текста

## Два режима работы — и это инженерно красиво

### Direct Mode (по умолчанию)

Реальный bash плюс прямые операции с файлами. Перед каждым изменением спрашивает подтверждение (y/N). Для автономного режима — флаг `--yes`, и агент работает без остановок.

### MCP Mode (--mcp)

Безопасный конфайнмент:

- Все пути заперты в директории проекта
- `.env` и `.git` заблокированы
- Bash недоступен
- С флагом `--dry-run` — превью diff без записи на диск

Один и тот же `ChatAgent` под капотом. Меняется только бэкенд инструментов. Никакой магии — чистая инженерия.

## Демо-сценарии, на которых проверяла

| Сценарий | Что делает |
|----------|------------|
| Генерация CHANGELOG.md | Парсит историю коммитов, формирует документ |
| Поиск API-ссылок | Ищет все упоминания по проекту |
| Создание ADR | Берёт контекст из кода |
| Проверка инвариантов | «Никаких секретов в клиентском коде» |

Каждый шаг — это function calling над файловыми тулами: `fs_read`, `fs_grep`, `fs_create`, `fs_edit`. После правок автоматически `run_checks` для синтаксиса Python.

## Технические детали

- **Модель**: DeepSeek
- **Основа**: порт наработок из дней 31–32 на MCP
- **Diff-обработка**: свой diffutil
- **Воспроизводимость**: повторный запуск той же цели даёт эквивалентный результат
- **Откат**: `git checkout` работает штатно

## Почему это круто

Агент **инициирует работу с файлами сам**, не ждёт команды «открой файл X». Это принципиально другой уровень автономности. Два режима — для разных сценариев: хочешь полный контроль — Direct, хочешь безопасность — MCP.

Если устали от болтунов, которые «думают, что делают» — смотрите код. Честный goal-oriented подход без иллюзий.
