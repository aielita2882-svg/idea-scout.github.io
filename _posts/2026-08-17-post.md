# Anthropic Cybersecurity Skills: Стандарт навыков для AI-агентов

Проблема большинства AI-агентов в сфере SecOps — фрагментация знаний. Модели часто галлюцинируют в специфических протоколах или предлагают общие советы из учебников, которые бесполезны в реальном пентесте или при мониторинге инфраструктуры. Anthropic решили эту проблему, создав структурированный датасет из 817 конкретных навыков кибербезопасности.

Это не просто список терминов, а полноценный фреймворк, который превращает LLM из «умного чат-бота» в специализированного агента, способного оперировать тактиками реальных злоумышленников.

### Технический стек и совместимость

Проект реализован на Python и распространяется под лицензией Apache 2.0, что позволяет беспрепятственно интегрировать его в коммерческий софт. 

Главная ценность — нативная совместимость с основным стеком инструментов разработки:
* **IDE и CLI:** Cursor, GitHub Copilot, Claude Code, Codex CLI, Gemini CLI и еще 20+ платформ.
* **Интеграция:** Набор навыков легко скармливается в системный промпт или используется для RAG-систем, чтобы ограничить область поиска модели и повысить точность ответов.

### Архитектура знаний

База охватывает 29 доменов безопасности (от Network Security до Vulnerability Management) и опирается на индустриальные стандарты. Вместо того чтобы надеяться на веса модели, агент получает доступ к логике следующих фреймворков:

1. **MITRE ATT&CK и ATLAS** — тактики и техники атакующих (включая специфику AI-систем).
2. **NIST CSF 2.0 и AI RMF** — стандарты управления рисками и кибербезопасности.
3. **D3FEND и MITRE F3** — стратегии защиты и противодействия.

### Практическое применение

Как это использовать в реальных проектах:

* **Автоматизация SOC:** Создание агентов для первичного анализа алертов. Агент, вооруженный этим набором навыков, будет классифицировать инцидент не по ключевым словам, а согласно матрице MITRE ATT&CK.
* **DevSecOps пайплайны:** Интеграция в CI/CD для автоматического аудита кода. Вместо общего «исправьте эту уязвимость», агент может предложить конкретный паттерн защиты из D3FEND.
* **AI Red Teaming:** Быстрое развертывание сценариев атаки для проверки устойчивости собственных систем, используя структурированные тактики из репозитория.

### Субъективная оценка

**Почему это круто:** 
Проект переводит разговор об AI в безопасности из плоскости «посмотрите, как модель пишет эксплойты» в плоскость «как создать надежный инструмент автоматизации». Это фактически стандарт API для знаний по безопасности, который убирает необходимость вручную прописывать сотни инструкций в системном промпте.

**Подводные камни:**
Наличие навыка в базе не гарантирует, что модель выполнит его безошибочно. Это «карта знаний», а не исполняемый код. Качество результата всё равно зависит от базовой модели (Claude 3.5 Sonnet или GPT-4o) и качества вашего промпт-инжиниринга. Также стоит помнить, что автоматизация действий в сети на основе этих навыков требует жесткого контроля (Human-in-the-loop), чтобы агент случайно не положил продакшн в попытке «проверить уязвимость».

**Вердикт:** 
Must-have для всех, кто строит AI-агентов для SecOps. Это кратчайший путь от общего LLM к специализированному инструменту кибербезопасности.
